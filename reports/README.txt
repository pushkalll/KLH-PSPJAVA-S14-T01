REPORTS FOLDER

This folder holds the final project report for the ATM Simulator.

The report covers:
  1. Introduction, problem statement and objectives
  2. System requirements
  3. System analysis (functional requirements)
  4. System design (class diagram, algorithm, flowchart, data structure)
  5. Implementation with the code used for each CO
  6. Testing: 18 test cases and sample output
  7. Conclusion
  8. Limitations and future scope
  9. References, plus the full source code
